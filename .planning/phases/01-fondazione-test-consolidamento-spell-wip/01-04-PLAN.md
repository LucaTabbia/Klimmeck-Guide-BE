  <action>
Creare `.github/workflows/ci.yml`. Requisiti (D-10/D-11/D-12):
- **Trigger:** `on: push` (ogni branch) — feedback continuo anche sui branch di fase, non solo sulle PR. Aggiungere anche `pull_request` per completezza.
- **Node:** usare Node 22 (allineato al runtime locale v22.12.0 verificato nel research) via `actions/setup-node@v4` con `cache: 'npm'`.
- **Redis service container:** reale, per i processor test (no ioredis-mock):
```yaml
    services:
      redis:
        image: redis:7
        ports: ['6379:6379']
        options: >-
          --health-cmd "redis-cli ping" --health-interval 10s
          --health-timeout 5s --health-retries 5
```
- **Cache binari mongodb-memory-server:** con `actions/cache@v4` sul path `~/.cache/mongodb-memory-server` e chiave che include una versione MongoDB pinnata. Impostare env `MONGOMS_VERSION` (es. `8.0.4`, una release ≥7.0 wiredTiger) per rendere la chiave cache deterministica.
- **Env per la suite:** `REDIS_HOST: localhost`, `REDIS_PORT: 6379` così `test/setup/redis.ts` usa il service container invece di scaricare redis-memory-server.
- **Step:** checkout → setup-node (cache npm) → restore cache binari Mongo → `npm ci` → `npm run lint` → `npm run test:unit` → `npm run test:int`.
- **Security:** nessun secret nel workflow; nessuna credenziale reale (gli env sono host/port locali del container). Non loggare/echoare variabili sensibili.

Struttura di riferimento:
```yaml
name: CI
on:
  push:
  pull_request:
jobs:
  test:
    runs-on: ubuntu-latest
    env:
      MONGOMS_VERSION: '8.0.4'
      REDIS_HOST: localhost
      REDIS_PORT: '6379'
    services:
      redis:
        image: redis:7
        ports: ['6379:6379']
        options: >-
          --health-cmd "redis-cli ping" --health-interval 10s
          --health-timeout 5s --health-retries 5
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'npm'
      - uses: actions/cache@v4
        with:
          path: ~/.cache/mongodb-memory-server
          key: mongoms-${{ runner.os }}-${{ env.MONGOMS_VERSION }}
      - run: npm ci
      - run: npm run lint
      - run: npm run test:unit
      - run: npm run test:int
```
