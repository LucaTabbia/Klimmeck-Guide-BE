Algoritmo (ordine dei tiri fisso, candidati ordinati per id):
1. `zone = zonePoolOf(...)`, `fallback = fallbackPoolOf(...)`.
2. Boss solo se `BOSS_PARTY_AVERAGE_PE[rank]` esiste (adventurer..hero): un tiro `chance.next() < BOSS_SHARE`; se vero, candidati `isBossCandidate(xp, rank)` nella zona, altrimenti nel ripiego; se presenti, uno scelto con un tiro (`index = min(len − 1, floor(next × len))`) → `{ type: boss, enemies: [{ enemy, quantity: 1 }], seats: bossSeatsOf(xp, media) }`; altrimenti si prosegue come `enemy`. Per rookie e legend nessun tiro del boss.
3. Legend: `legendPack(pool)` su zona, poi ripiego: unità = `LEGEND_PACK_UNITS.min + floor(next × 3)` (2–4), tipi = `1 + floor(next × min(MAX_PACK_TYPES, unità))` distinti scelti con tiri fra i candidati xp in fascia hero, ogni tipo con quantità 1, le unità restanti assegnate una per tiro a un tipo scelto; somma sempre in fascia legend. Pool senza candidati hero → prova il ripiego → `null`.
4. Altri ranghi: un tiro `next() < SINGLE_FORM_SHARE` sceglie (a), altrimenti (b); si prova la forma scelta poi l'altra sulla zona, poi le due sul ripiego; nessuna → `null`. (a) = un candidato con xp in fascia (un tiro). (b) = fino a `PACK_ATTEMPTS` tentativi: candidati xp ≥ 1 e < `min` della fascia; tipi = `1 + floor(next × MAX_PACK_TYPES)` (limitati ai candidati), scelti distinti con tiri, quantità 1; finché somma < `min` e unità < `MAX_PACK_UNITS` aggiungere un'unità a un tipo scelto con un tiro; valido se `min ≤ somma ≤ max` e `2 ≤ unità ≤ MAX_PACK_UNITS`.
5. `seats = 1` per le enemy (D-09); voci del branco nell'ordine di scelta.
