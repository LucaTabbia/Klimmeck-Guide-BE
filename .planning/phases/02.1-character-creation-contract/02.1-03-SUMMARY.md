# Phase 02.1 Plan 03: Create character input validation Summary

**Validazione autoritativa e pura di `CreateCharacterInput` (nome NFC/’→'/spazi compressi con charset Unicode e almeno una lettera, età dalla tabella unica `race-traits`, background ≤ 500 grafemi, imagePath https ≤ 2048) più il DTO GraphQL con enum registrati e senza campi di identità**

## Performance

- **Duration:** ~2 min
- **Completed:** 2026-10-09
- **Tasks:** 2/2
- **Files:** 7 creati

## Accomplishments

- `countGraphemes` con `Intl.Segmenter('it', { granularity: 'grapheme' })`: una famiglia emoji ZWJ conta 1, `É` conta 1
- `normalizeCharacterName` (NFC → `’`→`'` → trim → `\s+`→`' '`, quindi anche NBSP e tab) e `isValidCharacterName` (2–20 grafemi, `^[\p{L}' -]+$`, almeno una `\p{L}`): rifiuta cifre, simboli, emoji, ZWJ, nomi di sola punteggiatura (`--`, `''`, `- '`) e input non normalizzati
- `CreateCharacterInput` (`@InputType`): `name: String!`, `sex: SexType!`, `pronoun: PronounType!`, `race: RaceType!`, `classType: ClassType!`, `age: Int!`, `background: String`, `imagePath: String`; nessun `userId`/`twitchId`/`id`/`status`/`assets`/`quests` (T-02.1-01); `CharacterInfosInput` invariato
- `validateCreateCharacterInput`: nome → `CHARACTER_NAME_INVALID`, età → `CHARACTER_AGE_OUT_OF_RANGE` (via `isAgeAllowedForRace`, estremi inclusi), background assente/null/vuoto → `''` e > 500 grafemi → `BAD_USER_INPUT`, imagePath assente/null/vuoto → `null` e non-https / non-URL / > 2048 → `BAD_USER_INPUT`; risultato con esattamente 8 chiavi anche se il client inietta `userId`/`status` (T-02.1-02)
