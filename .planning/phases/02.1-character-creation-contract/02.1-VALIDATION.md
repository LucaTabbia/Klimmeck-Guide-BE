## Sampling Rate

- **After every task commit:** quick run unit + l'int-spec toccato dal task (`npx jest <int-spec> --selectProjects integration --runInBand`)
- **After every plan wave:** `npm test`
- **Before `/gsd-verify-work`:** `npm test` verde, `npm run build` ok, `npx tsc --noEmit -p tsconfig.build.json` ok, eslint pulito sui file toccati, `git diff --exit-code src/schema.gql` dopo la rigenerazione
- **Max feedback latency:** ~60 s per task
