Regole di `settlementOf` (pure, nell'ordine):
1. `curveOf(leg) = { distanceKm, uncoveredKm: food.uncoveredKm, hpLostTotal: food.hpLostTotal }`; `mealDue = food.foodConsumedAt === null && (moment !== 'progress' || targetKm >= food.coveredKm)`.
2. Fabbisogno del pasto: `progress`/`arrival` → `food.needed`; `stop` → `distanceKm > 0 ? Math.min(food.needed, foodNeededFor((durationMs * targetKm) / distanceKm)) : food.needed`.
3. `selection = mealDue ? selectFood(fabbisogno, stacks) : nessuna`; `ownedItems = consumed.length > 0 ? applyTradeToInventory(assets, mealLinesOf(consumed)).ownedItems : null`.
4. Fail-safe (D-19) SOLO per `progress` con pasto: `U' = uncoveredKmOf(food.needed, selection.covered, distanceKm)`; se `U' !== food.uncoveredKm` → `curve = { uncoveredKm: U', coveredKm: coveredKmOf({ distanceKm, uncoveredKm: U' }), hpLostTotal: hpLostFor(U') }` e la fame di questo passo usa la curva nuova.
5. `hpLoss = hungerBetween(curva in vigore, food.settledKm, targetKm)`.
6. `null` se `hpLoss === 0 && consumed.length === 0 && !(moment === 'progress' && mealDue)`.

Numeri delle prove (strada di 20 km in un'ora, piano `{ needed: 20, uncoveredKm: 10, coveredKm: 10, hpLostTotal: 55, settledKm: 0, foodConsumedAt: null }`, cibo `F1` power 1; strada di 400 km in 144 000 000 ms, piano `{ needed: 800, uncoveredKm: 120, coveredKm: 280, hpLostTotal: 7260 }`, cibo `F20` power 20 × 28 = 560 power).
