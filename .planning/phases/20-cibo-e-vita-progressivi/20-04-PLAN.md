Forma di `settleDue` (RESEARCH Code Examples «Assestamento nello sweep»):
1. `find(foodTravellersFilter(), FOOD_TRAVELLER_PROJECTION).lean().exec()`.
2. Per ciascuno, in serie: `leg = foodLegOf(travel)`; `null` → `logger.warn(\`Viaggio del personaggio ${id}: piano del cibo non valido, ignorato\`)` e avanti; `!settlementIsDue(leg, reachedKmOf(travel, now))` → avanti (nessuna transazione, nessuna scrittura).
3. Dovuto → `try { … } catch (error) { logger.error(\`Fame del viaggio del personaggio ${id} fallita: ${describeError(error)}\`) }` attorno a una transazione: callback che riparte da zero (oggetto `outcome` azzerato all'inizio, come `complete`), `findOne(foodTravellerFilter(id, startTime), FOOD_TRAVELLER_PROJECTION).session(session).lean()`, `foodLegOf` di nuovo (null → nessuna scrittura), `pantry.read(id, session)`, `settlementOf({ leg, targetKm: reachedKmOf(travel, now), moment: 'progress', lifeNow: pantry.hpBefore, assets: pantry.assets, stacks: pantry.stacks, now })`, null → nessuna scrittura; altrimenti `updateOne({ ...foodTravellerFilter(id, startTime), ...settlementGuardsOf(leg.food, settlement, pantry.hpRaw) }, { $set: { ...settlementSetOf(settlement), ...foodProgressSetOf(settlement) } }, { session })`; `matchedCount === 1` → assestato.
4. Dopo il commit: se l'esito ha `curve`, `logger.warn(\`Viaggio del personaggio ${id}: cibo cambiato al confine, km scoperti ${prima} → ${dopo}\`)`; a fine giro, se > 0, `logger.log(\`Sweep della fame: ${n} viaggi assestati\`)`.
