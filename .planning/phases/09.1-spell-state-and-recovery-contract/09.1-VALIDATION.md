|----------|-------|

| **Estimated runtime** | ~5 s unit, ~180 s integration |

## Sampling Rate

- **After every task commit:** Run `npx jest src/characters src/quests/outcomes src/config src/models src/gameRules test/fixtures --selectProjects unit` (+ l'int-spec del task con `--selectProjects integration --runInBand`)
- **After every plan wave:** Run `npm run test:unit && npm run test:int`
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 60 s per task (int-spec del task)
